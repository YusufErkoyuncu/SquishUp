# Eksen Works website

Official website and public resources for Eksen Works projects.

The site is intentionally built as a small, dependency-free static website for
GitHub Pages. It includes:

- the Eksen Works landing page;
- the Squish Up privacy policy;
- the support page; and
- an `app-ads.txt` placeholder that contains no live seller record until the
  exact AdMob publisher line is confirmed.
